# 02. Role Catalogue


Northwind Health’s billing access has grown by copying permissions from “someone similar.” This is hard to maintain, creates privilege creep, and does not scale as the company grows.

I propose six reusable roles. Each role is based on actual job responsibilities so new joiners receive consistent access without inheriting someone else’s permissions.

## Proposed Role Catalogue

| Role                  | Permissions                                                                 | Intended Use                                                                 |
|-----------------------|-----------------------------------------------------------------------------|------------------------------------------------------------------------------|
| **Support Agent**     | View Invoices                                                               | View invoices only. For support staff who need to look up billing information. |
| **Finance Analyst**   | View Invoices, Export Patient Billing Data                                  | View invoices and export patient billing data for reporting. Exports should be logged and reviewed. |
| **Billing Specialist**| View Invoices, Create Invoice, Edit Invoice, Issue Refunds                  | Create and edit invoices, and issue refunds. Refunds above an agreed threshold should still require prior approval. |
| **Finance Manager**   | View Invoices, Approve Refunds, Export Patient Billing Data                 | Approve refunds and export data. Does **not** create, edit or delete invoices. |
| **IT Admin**          | Admin Settings                                                              | Application configuration only. No access to invoices or financial transactions. |
| **External Auditor**  | View Invoices                                                               | Read-only access, ideally time-limited for the duration of the audit.        |

<BR>

*Permissions are limited to the minimum needed for each role’s tasks.*

<BR>


## Design Decisions

- **Least privilege**: each role contains only what the job requires.
- **Segregation of duties**: Approve Refunds and Issue Refunds are deliberately placed in different roles.
- **Delete Invoice**: is not included in any standing role. It will be handled as a break glass permission that requires approval and full logging.

- Finance Manager deliberately does **not** receive create, edit or delete rights. This keeps approval independent from invoice preparation.

<BR>

## Limitations

These roles define what actions a user can perform. They do not by themselves stop someone being given two conflicting roles, and they do not control which individual patient records a user can see. **Application level controls** and **regular access reviews** are still required.

<BR>

  
### Designed for Growth and Scalability

- **Existing employees:** Review current access, assign the correct role, and remove anything unnecessary.
- **Future employees:** Assign the approved role at onboarding instead of copying another person’s permissions.
